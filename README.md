# 靈魂之窟

瀏覽器上玩的抽牌 roguelike 遊戲。整個遊戲就是一個檔案：`index.html`。

## 怎麼玩
打開網頁就能玩，不需要登入。進度存在各人自己的瀏覽器裡。
主選單的「💾 存檔／讀檔」可以複製存檔碼備份，換裝置或清除瀏覽器資料前請先存檔。

## 更新方式（給網站管理者）
1. 取得最新的 `index.html`（檔名一定要是 index.html）。
2. 到這個 repository → Add file → Upload files，把新的 index.html 拖進去。
3. 按 Commit changes。
4. 等 1～2 分鐘，網站自動更新；玩家若看到舊畫面，請強制重新整理（電腦按 Ctrl+F5）。
